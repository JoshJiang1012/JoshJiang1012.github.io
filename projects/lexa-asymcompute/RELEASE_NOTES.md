# Lexa AsymCompute 2.0.0

This release turns the earlier narrow prototype into a general asymmetric-compute modelling toolkit.

Highlights:

- general GPU/CPU/RAM/NVMe/edge workload model;
- complete formula set in README;
- capacity and transfer constraints;
- latency/energy weighted optimization;
- observed VM and synthetic trace-pipeline data;
- strict analytical-versus-observed provenance;
- optional sparse-routing analysis;
- 19 unit/integration tests;
- Python 3.10–3.12 CI;
- schemas, contribution guide, benchmark protocol and roadmap.
