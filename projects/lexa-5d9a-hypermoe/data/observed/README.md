Place real, documented measurements here using the experiment protocol and
schemas. Suggested layout:

```text
observed/<campaign-id>/
├── metadata.json
├── raw-runtime.log
├── router-trace.jsonl
├── latency.csv
└── summary.json
```

Avoid committing prompts, completions, secrets, proprietary code, or customer
data.
