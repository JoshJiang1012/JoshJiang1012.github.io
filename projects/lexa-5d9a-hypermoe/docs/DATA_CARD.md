# Data card

## Dataset classes

### `synthetic_analytical`

Rows generated directly by the equations in `src/lexa_hypermoe/model.py`. These
are reproducible parameter sweeps, not machine measurements.

### `synthetic_distribution`

Zipf-distribution sensitivity data. It explores possible Expert skew but does
not assert the true GPT-OSS router distribution.

### `synthetic_latency`

Prefetch horizons computed from declared target throughput and assumed load
latencies.

### `analytical_requirement`

Probability or capacity requirements derived from formulas.

### `synthetic_router_example`

Small route records used only for parser examples and tests. They are not output
from GPT-OSS.

### `observed_router_metadata`

Route events emitted by the pinned collector from an actual runtime. A valid row
contains sequence index, layer, selected Expert IDs, phase, batch size, domain,
and source. It does not establish model speed or answer quality.

### `observed_benchmark`

Trace-disabled timing measurements with full hardware, runtime, model, and
measurement provenance.

No observed GPT-OSS-120B RTX 4080 benchmark is bundled in version 0.2.0.

## Generation

```bash
python scripts/generate_data.py
```

Synthetic generation is deterministic and uses only the Python standard library.
Observed traces are never regenerated by this command.

## Intended use

- research planning;
- sensitivity analysis;
- runtime design reviews;
- measuring real static-cache and temporal-locality properties;
- selecting whether to implement a dynamic Expert cache;
- identifying measurements needed before performance claims.

## Out-of-scope use

- advertising synthetic values as hardware benchmarks;
- inferring model quality from throughput equations;
- claiming an exact speed without raw logs and a documented runtime;
- publishing prompts, completions, token IDs, logits, or hidden states;
- treating a trace-enabled run as an uninstrumented throughput benchmark.

## Privacy

The v2 parser rejects prompt text, generated text, token IDs, logits,
probabilities, embeddings, residuals, hidden states, credentials, and unknown
fields by default. Run manifests retain only a prompt digest and byte count.

Do not publish private model paths, customer identifiers, proprietary prompt
labels, or confidential filenames in public domain labels or run manifests.
