# Changelog

## 2.0.0

- renamed the project to Lexa AsymCompute;
- generalized the engine beyond one model or one hardware profile;
- added FLOP, memory, resident-capacity, link-transfer, energy and serial-work terms;
- added constrained N-device simplex optimization;
- added asymmetry and fairness metrics;
- embedded the complete implemented formula set in README;
- added observed VM and synthetic-pipeline measurements;
- added schemas, provenance rules, benchmark protocol and use-case guidance;
- retained an optional sparse-routing specialization and privacy-safe trace evaluator.
